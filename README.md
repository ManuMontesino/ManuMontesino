#### 🎛️ Featured project: [midi-controller](https://github.com/ManuMontesino/midi-controller)

A USB-MIDI + HID controller built on a bare RP2040 chip, with:

- 8 encoders with LED rings
- 8 mechanical keys with RGB LEDs
- 144 LEDs driven by an IS31FL3741A over I²C
- 32 inputs read through a chain of shift registers
- TRS MIDI out and an expansion header

The hardware design is finished: KiCad 9, 4 layers, a clean ERC/DRC and production files for JLCPCB. Firmware is in progress, using the Pico SDK and TinyUSB.

**Hardware:** KiCad · PCB design (4-layer, fine-pitch QFN) · RP2040 · DFM for JLCPCB assembly
